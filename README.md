## Featured Projects

### AI for healthcare workflows
- **[MedMail](https://github.com/OG-Dhai/medmail-showcase):** I independently developed this AI-powered application for classifying medical practice emails. It uses a local language model through Ollama, schema-validated outputs, deterministic safety rules and staff review of every draft, and runs on synthetic data. Project description only; the source code is not published.

### Computer vision
- **[Body Explorer](https://github.com/OG-Dhai/body-explorer):** A webcam game that teaches young children the names of their body parts. Pose, hand and face tracking run in the browser with MediaPipe, so no camera data leaves the device. Offline-capable PWA in five languages.

### Backend architecture
- **[Queue Worker Architecture Notes](https://github.com/OG-Dhai/queue-worker-architecture-notes):** A case study from paid freelance work for a client: moving periodic checks of slow external sources out of a sequential polling script into BullMQ queue workers, with retries, failure isolation and Prometheus-based monitoring. The client-owned source code is not published.

### Graphics and simulation
- **[Solar System Simulator](https://github.com/OG-Dhai/solar-system-simulator):** A real-time solar system in the browser, with Kepler orbits computed at runtime, GLSL shaders and a WebXR VR mode. Course project at HTW Berlin.
